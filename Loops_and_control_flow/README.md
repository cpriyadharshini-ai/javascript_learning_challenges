# Day 03 – Loops, Break, Continue & Control Flow

## 📚 Topics Learned

Today, I learned how to control program execution using JavaScript loops, conditional statements, and loop-control keywords.

### 1. Loops
- **for loop** – Executes a block of code repeatedly for a specified number of iterations.
- **while loop** – Executes code as long as a condition is true.
- **do...while loop** – Executes the code at least once before checking the condition.

### 2. Break Statement
- Terminates the loop immediately when a specified condition is met.

### 3. Continue Statement
- Skips the current iteration and moves to the next iteration.

### 4. Control Flow
- if, else if, else statements
- Nested if conditions
- Conditional decision-making
- Number classification and grade calculation
