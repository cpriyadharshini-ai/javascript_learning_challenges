# Day 04 – JavaScript Arrays & Array Constructor

## 📚 Topics Learned

Today, I learned the fundamentals of JavaScript arrays and array creation using the Array constructor.

### 1. Array Basics
- Creating arrays using square brackets `[]`
- Accessing array elements using indexes
- Updating array elements
- Finding array length using `length`
- Understanding zero-based indexing

### 2. Array Constructor
- Creating arrays using `new Array()`
- Understanding the difference between array literals and array constructors
- Creating arrays with predefined elements or lengths
